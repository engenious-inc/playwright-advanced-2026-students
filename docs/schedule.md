# Release schedule

**This file is the authoritative schedule.** Lecture 1.D says to check here rather than trust
any date said on camera — this is that page. If a release moves, this table is what changes.

Modules release in syllabus order: **M0 (orientation), then M1 → M20.** The module number, the
release order, and the "Module N" label you see in the course are all the same number — there is
no separate internal numbering. Lessons are lettered off the module number (`1.A`, `1.B`, and so
on).

Module 0 is a short orientation video that ships alongside the debut, **Module 1**.

## If a date moves

Dates can shift. The **order never does** — M1 through M20 always ship in sequence, so the
module you are on is always followed by the next number up. When something moves, this table is
updated first.
